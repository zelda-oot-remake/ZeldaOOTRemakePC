# Zelda Ocarina Of Time Remake PC Port

**Zelda Ocarina Of Time Remake PC Port** opens the hyrule gate, indexed as the legend of zelda ocarina of time. It maps how ocarina of time emulator paths boot the deku tree and ocarina of time switch 2 behaves; an oot remake rom stays yours.

1. Extract the archive.
2. Point it at a dump you already own.
3. The deku tree is the steadier area; field haze is still rough.
4. Notes in `files/notes/`.
